# Security Policy

## Supported Versions

Currently, only the latest release of SwarmGuard AI receives security updates. 

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

Security is a top priority for SwarmGuard AI. We take all security vulnerabilities seriously.

If you discover a security vulnerability within SwarmGuard AI, please send an e-mail to the security team rather than creating a public issue. We will strive to acknowledge your report within 48 hours and provide a timeline for a fix.

Please include the following information in your report:
- Description of the vulnerability.
- Steps to reproduce the vulnerability.
- Potential impact.
- Any suggested mitigations.

Public disclosure of vulnerabilities before a patch is released is strictly prohibited and violates our community guidelines.
